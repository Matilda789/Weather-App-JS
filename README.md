# Weather-App-JS
Простое погодное приложение на чистом JavaScript. Есть поиск по городу, показ текущей погоды.

## Возможности
- поиск по городу кнопкой или Enter;
- показ текущей погоды: иконка, температура, ощущается как, влажность, скорость ветра, осадки;
- показ состояния загрузки/ошибки/результата;
- обработка ошибок: пустой ввод, неточное название города, отстутствие сети.

## Стек
- HTML5;
- CSS;
- JavaScript;
- WeatherAPI.com.

## Как запустить
Открыть index.html в браузере или запустить через локальный сервер.

Приложение использует бесплатный API.
Ключ хранится в scripts/main.js в переменной API_KEY.
Свой ключ можно получить после регистрации в личном кабинете WeatherAPI.com.
